Finally, the curation scripts should be added to the paper’s repository. A best practice is to follow a **“one task, one script”** approach: each script should be isolated and granular, perform a single well-defined task, take a clear input, and produce a specific output.

It is also recommended that these granular scripts be manageable via command-line arguments, for example:

```bash
python search-yt-api.py --query ABC --duration long --region BD
```
