Your job is to read a JSON array of Bengali or code-mixed Bengali-English medical text samples and, for each sample independently, extract all medically meaningful entity mentions as exact substrings from that sample’s original text, then assign each extracted substring exactly one valid entity label from the allowed label set. You must not hallucinate, paraphrase, normalize, translate, merge across samples, or rewrite text: every extracted entity must appear exactly and sequentially in its own input sample. Your output must be valid JSON only, following the required array schema exactly.
